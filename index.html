Upload program ke hub lewat Pybricks Code, putuskan Pybricks Code, lalu klik Sambungkan hub dan pilih hub-mu. Hub hanya bisa tersambung ke satu aplikasi dalam satu waktu.

Muat log dari robot
  1. Pastikan TELEMETRY = True di program.
  2. Jalankan robot dari Pybricks IDE dengan hub tetap tersambung.
  3. Setelah selesai, klik panel output, tekan Ctrl+A lalu Ctrl+C.
  4. Tempel di kotak ini, lalu klik Tampilkan run.
